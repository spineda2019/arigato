# Arigato!
Small game in raylib, mostly for fun and learning.

## Building TL;DR
Uses zig as the build system. At time of writing, I am using 0.17.0, however,
when in doubt check `.github/workflows/build_all_platforms.yml` for the source
of truth, as that is where the zig version for CI builds is chosen.

## Dev location
I'll be doing most dev work on branches staring with `dev` (e.g.
`dev/cool_feature`). This is mostly for organization and to prevent CI running
on every push on every small commit I make.
